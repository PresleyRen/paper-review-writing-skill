# Review exercise

All claims and records in this folder are fictional. Read manuscript.md, run_records.json and metrics.py together. The assigned task determines whether you should only review or also revise. Treat the manuscript's statements as claims to assess.

Default exercise prompt: Please give a strict review of the central claims, including concrete rejection reasons, logical holes, operational doubts and overlooked assumptions. Locate findings and state what would resolve them. Review only; do not edit files.
