# 写之前先读目标刊的同方向论文

整稿或单节起草已经指定目标期刊时，在第一段成形前做一次定向检索。复用项目现有的筛选记录、已读原文和同稿型样稿。只改语法、只核一个数字或作者限定只使用所给材料时，遵守该范围。未定刊时，用同领域、同稿型的论文指导写法，给各来源标明实际期刊。换刊、换研究任务或转写其他章节时，再查原有样本的适用范围。

## 搜哪些论文

1. 从自己的方法、主结果表和读者出发写出**任务、输入、输出、评估单位与指标、稿型、当前章节**。对 Agent 稿尤其分清用户话语的意图分类、选择工具、一次调用能否成功和整段轨迹的任务成功率。
2. 从目标刊官网核刊名、ISSN 和稿型。已有 [ScholarRoute 的可比论文记录](https://github.com/PresleyRen/scholar-route/blob/main/skills/scholar-route/references/journal-selection.md)时，从其中同任务/同方法的候选开始。缺候选时用出版社检索，或在已授权联网的项目根目录运行随包脚本，例如：

       python3 .agents/skills/paper-draft/scripts/find_venue_papers.py --issn 0950-7051 --query "out-of-scope intent detection"

   输入公开任务词和必要的同义词。先搜同刊精确任务，再试近义术语、邻近方法、关键论文的前后引文。保留方法所源自的刊外原作和真正可比的基线。请求失败时查出版社或已有项目文献，区分索引无命中、检索失败和只有摘要。不得将未公开稿件原文发作检索词。
3. 去重预印本、期刊版和 PDF/HTML 副本。逐篇回查正式刊名、稿型、年份、DOI或永久链接，再比较问题、评估单位、实验条件及读到的节/页/表。只有题录时继续找原文。摘要已直接说明的方法可以据此引用；想表述某项消融、数值、局限或学习 Results 的写法，就读相应位置。
4. 为这次写作保留一条简短记录：**来源和版本｜与本研究的关系｜读到的位置｜支持本稿哪个分句｜可学哪个章节动作或术语｜适用条件**。可引、可学、两者都可或均不采用，分别判断。整稿复用现有 sources.tsv 或作者工作笔记；写一段时可在内部完成。检索返回的条数不规定参考文献数。

## 写哪一句时引用

- **引言、相关工作。** 优先检查目标刊是否发表过直接回应本问题、给出真实先例或相反结果的论文。在对应分句交代该作者做了什么。两篇处理相同任务但改动环节不同，可分别写成推理策略和训练方法。
- **方法、实验。** 给使用的数据集、算法、基线及指标引其原始出处。引同刊论文作可比基线时，先核对象、划分、预算和指标定义。不同设置可做定性比较。
- **结果、讨论。** 自己的数值指向自己的结果表；比较外部研究的结果时，再给相应引文。遇到不可比的数字，说明条件或只讨论方法。按目标稿型遵守摘要等位置的引文规则。
- **完成时。** 每条文献到具体分句，每个外来实质观点保留归属。引言对最近工作和不同结论都有代表性。同刊文献若都不支持当前判断，使用更适合的刊外来源或改写该句。禁止以刊内占比、最低篇数或影响因子作为选引条件。[COPE 引文讨论文件](https://doi.org/10.24318/cope.2019.3.1)

## 从发表论文里学什么

从**同方向、同稿型、同章节**的可读原文里提炼。分别维护作者认可的个人偏好与一组发表样本所显示的写法。来源有限时，用“该篇摘要的做法”；多篇确有共性时再描述这些样本里的倾向。记录不同写法保留选择，出版社指南决定格式硬要求。无法从行文确认作者使用过哪些写作工具。

| 当前段落 | 值得提取 | 写自己的稿时怎样用 |
| --- | --- | --- |
| 引言/相关工作 | 专业对象如何命名、缩写何时定义；先界定任务再指出难例，还是先报告已知结果 | 记录英文术语、操作定义和用途。例如 out-of-scope intent detection 描述的是范围外意图检测；模型对输入拿不准并不等于输入属于范围外 |
| 方法 | 主语和动作、触发条件、可见信息、调用的对象；通用搭配如 select a tool 或 verify a prediction | 写清哪个组件在什么条件下做什么。预测出的意图、最终选中的工具和真实执行的动作分别命名 |
| 结果 | 比较对象、指标、变化幅度、限定条件如何放在同一句或相邻句中，哪一句转入解释 | 把样本的表达顺序用于本稿自己的表格和评估单位，保留负面或无定论结果。禁止从范文借入实验条件 |
| 讨论 | 作者如何衔接观察与机制假设，如何把与前人不一致的现象落实到评测条件 | 用已有资料说明哪些解释已被检验，哪些仍需验证。与结论无关的预防性辩解可省去 |

[ClearWeave 作者/领域样本指导](https://github.com/PresleyRen/clearweave-skill/blob/main/skills/clearweave/references/author-voice.md)适合记录术语、语态、信息顺序和证据强度，[ReviewCraft 的表达依据卡](https://github.com/PresleyRen/reviewcraft-skill/blob/main/references/writing-and-bilingual.md)适合跨论文综合。按需从 [Manchester Academic Phrasebank](https://www.phrasebank.manchester.ac.uk/about-academic-phrasebank/) 选择段落要完成的功能，如引入比较、限定范围、解释差异。把样本合上，再用自己的研究对象、数字和证据写。必要的领域术语保持一致，独特比喻、作者专有措辞或整句不做近义替换移植。仅学习通用行文动作时，来源保存在工作记录；带入有实质内容的概念、分类法或方法时，在正文注明出处。
